## 개발 철학

> **Understand → Implement → Analyze → Improve**

기술을 단순히 사용하는 것보다 **왜 그렇게 동작하는지 이해하는 것**을 중요하게 생각합니다.

새로운 기술을 학습할 때에는 다음 과정을 반복합니다.

1. 핵심 개념과 원리를 학습합니다.
2. 직접 코드를 작성하여 동작을 확인합니다.
3. 발생한 문제의 원인을 분석합니다.
4. 구현 결과를 개선합니다.
5. 학습 과정과 결과를 문서화합니다.

이를 통해 단순한 기술 습득을 넘어 **문제를 정의하고 해결할 수 있는 개발자**로 성장하는 것을 목표로 하고 있습니다.
