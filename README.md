# 박세은

## 컴퓨터과학 · 정보보안 · 정보관리

컴퓨터과학과 정보관리를 전공하며 **정보를 효율적으로 관리하고 안전하게 활용할 수 있는 시스템**에 관심을 가지고 공부하고 있습니다.

프로그래밍과 컴퓨터 시스템의 기본 원리를 이해하는 것을 바탕으로, 데이터가 생성되고 저장되며 전달되는 과정에서 발생하는 보안 문제와 이를 체계적으로 관리하기 위한 정보시스템을 학습하고 있습니다.

새로운 기술을 학습할 때 다음의 과정을 중요하게 생각합니다.

```text

   ↓
```

## GitHub 운영 목적

이 GitHub는 단순한 코드 저장소가 아니라 **학습과 개발 과정을 체계적으로 기록하는 개인 기술 아카이브**입니다.

```text
GitHub
│
├── 학습
│   ├── 컴퓨터과학
│   ├── 프로그래밍
│   ├── 데이터베이스
│   ├── 네트워크
│   └── 정보보안
│
├── 프로젝트
│   ├── 정보관리 시스템
│   └── 보안 관련 프로젝트
│
├── 연구 및 과제
│
└── 기술 문서
```

학습한 지식을 기록하고, 직접 구현하며, 프로젝트를 통해 적용하고, 그 결과를 다시 문서화하는 과정을 지속적으로 관리하고 있습니다.
